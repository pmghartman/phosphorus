# Third-party notices

phosphorus ships no third-party source in this repository. The `phosphorus`
binary statically links the Go modules below, its embedded web client bundles
the npm packages below, the Phosphorus apps link the Rust crates of
`packaging/app/Cargo.lock`, and the host installers carry or fetch the rest
from their upstream publishers, unmodified. Each stays under its own license;
the phosphorus license (see `LICENSE`) covers none of them.

Every component's full license text, with its exact version, is in
`THIRD_PARTY_LICENSES.txt`, generated by `make licenses` (`cmd/licenses`) and
carried by every installer: the release tree on hosts, the app bundles'
resources, and `/usr/share/doc/phosphorus/` on Linux. Each release attaches it too.
